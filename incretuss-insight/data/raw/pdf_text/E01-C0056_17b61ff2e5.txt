РАСТИТЕЛЬНЫЕ ЭКСТРАКТЫ
Для производства экстрактов компания 
«Биолит» использует водную экстракцию эко-
логически безопасного растительного сырья. 
К каждому виду сырья подобраны щадящие 
технологические режимы, чтобы максимально 
сохранить биологически активные вещества, 
содержащиеся в сырье.
Компанией используется метод многократной 
перколяции (реперколяции) при экстрагирова-
нии растительного сырья.
Многократная перколяция — это процесс 
непрерывной фильтрации, процеживания 
экстрагента сквозь слой растительного сырья 
с целью извлечения растворимых в экстрагенте 
веществ.
Метод многократной перколяции вклю-
чает три последовательно протекаю-
щие стадии:
Сущность многократной перколяции заклю-
чается в использовании батарей диффузоров 
(перколяторов), при этом извлечение из одного 
перколятора используется для перколирования 
сырья в следующем перколяторе. Таким обра-
зом, экстрагент, проходя через такую батарею

ПРОДУКТОВ И БАД
Гранулирование — это процесс перевода 
порошков в конгломерированные частицы 
различной формы и размеров для улучшения 
растворимости, сыпучести продуктов.
Компания «Биолит» использует гранулято-
ры для наращивания когломератов с помощью 
нанесения растворов активных веществ на 
порошок. Сушка гранулята происходит в су-
шильных шкафах при комнатной температуре 
для сохранения заданных свой ств продукта.
Гранулирование применяется для создания 
быстрорастворимых форм напитков и гранули-
рованных видов БАД. В качестве основы для 
гранулирования используется сахар, глюкоза, 
сорбит, маннит, клетчатка и другие виды сырья.
Разработанные технологии позволяют по-
лучить различные формы гранулированной 
продукции, обеспечивая высокую степень 
биодоступности активных компонентов, а так 
же сохранить максимальную эффективность.
Компания «Биолит» предлагает своим заказчи-
кам уникальные возможности использования 
разработанных технологий для достижения 
любых целей выполнения задач по гранулиро-
ванию различных материалов.

цвета;
• возможность заполнения капсулы веществом 
в любой форме — порошок, гранулы, микро-
пеллеты.
Преимущества твердых желатиновых 
капсул:
• Возможность комбинации нескольких видов 
веществ в одной капсуле
• Защита от неблагоприятных внешних фак-
торов
• Контроль высвобождения активных веществ 
как по скорости, так и по локации действия
