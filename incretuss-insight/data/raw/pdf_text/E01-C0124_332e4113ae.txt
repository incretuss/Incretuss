Normal passage through the door
• The alarm delay is set on PIRS-CAN nodes for the alert level and the action limit (up to 12 hours) and in Gigrotermon-
ARM — synchronised with the hardware delay or set separately (up to 24 hours): a log event and a notification 
appear only if the excursion lasts longer than the set time, so a normal passage does not become an alarm.
• The delays set are assessed and justified within the contamination control strategy (cl. 4.16).
Acknowledgement
• Warnings and alarms are acknowledged by a user with the relevant permission, who adds a comment on the cause 
and the actions taken; the record goes to the event log with the user name and time.
• In CAN-bus architectures, manual acknowledgement can be enabled: the alarm state is held on the node and the 
alarm relay it controls even after the parameter returns to normal — until a dedicated operator confirmation in 
Gigrotermon-ARM.
• Comments in the event log are protected against deletion and editing.

Temperature and humidity: IPM-10, IPM-11
• Temperature −40…+60 °C (IPM-11 — from −10 °C), humidity 5–95 %; accuracy by 
modification: temperature ±1.0…±0.2 °C, humidity ±5.0…±1.5 %
• For cleanrooms — stainless steel housing with a sintered metal powder filter, 
designed for washing and disinfection; IP52
Differential pressure: IPM-41
• Differential pressure 0–50 Pa; accuracy by modification ±3.0…±1.5 Pa; for 10–
15 Pa differentials between adjacent grades — modification -03 (±1.5 Pa within 
0–20 Pa)
• Installed in the ceiling void: only the pressure sampling tube enters the clean 
zone
Low temperatures and atmospheric pressure:
IPM-21, IPM-22, IPM-30
• IPM-21: −80…+125 °C, IPM-22: −196…+125 °C — freezers and cryogenic storage; 
accuracy by modification ±5.0 or ±2.5 °C
• IPM-30: atmospheric pressure 30–110 kPa; accuracy ±0.2 kPa
HEPA filter loading: IPM-44
• Differential pressure across the HEPA filter −500…+500 Pa — filter loading 
indicator
• Not a type-approved measuring instrument; its data are not metrologically 
significant
Specifications by modification — slide 20. Order code example: IPM-10-22-4-2.
